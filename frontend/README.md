# Система оптимальной парковки

Адаптивный фронтенд для подбора свободного парковочного места по типу автомобиля и условиям поездки. Проект работает на React, TypeScript и Vite.

## Структура и запуск

Нужны Node.js 20+ и pnpm. Если команда `pnpm` не найдена, установите менеджер пакетов:

```bash
npm install --global pnpm
```

После установки закройте и заново откройте терминал, затем перейдите в папку `frontend/` (cd frontend).

```bash
pnpm install
pnpm dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:8443`). Основной экран — стартовая страница; кнопка «Найти подходящее место» открывает подбор. Для проверки сборки:

```bash
pnpm typecheck
pnpm build
```

## Что есть в интерфейсе

- стартовая страница с числом свободных мест и кратким обзором зон;
- схема парковки с занятыми и свободными местами;
- выбор типа автомобиля, потребности в зарядке и доступном месте;
- подбор подходящего места, альтернативы и маршрут от въезда;
- состояние отсутствия подходящих мест;
- адаптивная версия для телефона.

## Данные

План парковки, параметры мест, маршруты и занятость приходят с бэкенда (`src/api.ts`): `GET /api/spots` опрашивается раз в 5 секунд, подбор выполняется через `POST /api/recommendations`. В `src/parking.ts` находятся типы данных и функции отображения схемы. В режиме `pnpm dev` Vite проксирует `/api` на `http://localhost:8000` (адрес можно переопределить переменной `VITE_API_PROXY`), поэтому бэкенд должен быть запущен (см. `backend/README.md`). В Docker запросы `/api` проксирует nginx.

В папке проекта находятся приложение целиком, его `package.json`, lockfile, Vite и TypeScript конфигурации, HTML-точка входа и публичные ресурсы. Стартовая страница находится в `src/HomePage.tsx`, схема парковки — в `src/ParkingMap.tsx`, панели выбора и результата — в `src/Panels.tsx`, состояние экранов — в `src/App.tsx`.

На первой и второй странице используется Manrope. Для заголовка «Паркуйтесь с умом» сохранён отдельный шрифт Guano Apes. В `public/fonts` также сохранены Wremena и Kazuki Reiwa для сравнения; Kazuki Reiwa создан Kazuki Kimura и распространяется по лицензии SIL Open Font License 1.1 (`public/fonts/KazukiReiwa-OFL.txt`).

## Назначения и оператор

Кнопка «Закрепить место» создаёт назначение на backend. Интерфейс показывает таймер, отмену и результат парковки; сохранённый номер назначения восстанавливается при перезагрузке той же вкладки. Потеря места или закрытие пути открывают повторный подбор. При ошибке сети старые рекомендации не позволяют закреплять место.

Кабинет оператора содержит загрузку зон, показатели за 24 часа, фильтры и редактор мест, журнал событий, управление временем и доступностью участков проезда, импорт/экспорт JSON. План, размеры и маршруты приходят с backend, локального списка мест больше нет.

Сквозные тесты (временная БД, отдельные серверы, Chromium):

```bash
pnpm install
pnpm exec playwright install chromium
pnpm test:e2e
```

Backend-зависимости должны быть установлены в `backend/.venv` либо в Python, указанном в `FREESPOT_PYTHON`. На машине с Chrome можно запустить `FREESPOT_BROWSER_CHANNEL=chrome pnpm test:e2e`. Порты 18000 и 18443 должны быть свободны. Методика и ожидаемые результаты: [docs/acceptance.md](../docs/acceptance.md).
